# options-simulation 复现 — 2026-06-08

对照 `doc/legacy/options-simulation-report-2026-05-31.html`。

## 结论

**主要复现失败 / 数字结构性变化**。报告的 287 笔信号样本在新的 divergence engine
下扩大到 754 笔（×2.6），导致几乎所有 EV / 胜率 / 出场分布数字同步下移。
另外，报告依赖一个 Black 模型 + HV20 + 4-tick 止损的期权 P&L 仿真脚本，
该脚本不在当前仓库中，因此**期权 EV / 4-tick vs ATR 对比无法严格重算**；
我们只能用现有的真实期权 payoff CSV 做 ATM-代理的中位权利金对照。

## 4-tick vs ATR 对比

报告核心叙事："4-tick 止损把完全止损路径的损失从 -52% 压到 -9%，
节省 43 个百分点"。这是 Black 模型 + 时间价值衰减组合下的合成数字，
当前仓库**没有**对应的仿真脚本（不在 scripts/ 也不在 engine/）来重算。
有了 outcome 列后可以反推一个简化版（full_stop 出场 × 4tick=ε 损耗），
但与报告口径不一致，不强行还原。

## 总判定

**❌ 不能复现**：
1. 287 笔信号 → 754 笔（divergence engine 扩展，按 README 描述）
2. EV / 胜率 / outcome 分布全部下移（~50%）
3. 期权 EV、4tick 优势这些"二阶仿真"数字没有源脚本，无法严格重算
4. 报告"12 品种覆盖"在期权 payoff 数据里只有 8 个有数据，4 个完全为空

报告的**叙事方向**（4-tick 止损节省时间价值损耗、底部×opposing 是最稳健装置）
仍可能成立，但需要：
- 重新跑 Black 模型仿真（脚本缺失）
- 或锁回 2026-05-31 的 287 笔信号样本（旧版 divergence engine 输出）
- 或在新 754 笔样本上重做一遍仿真，预期 EV 将相应下降 50% 左右
