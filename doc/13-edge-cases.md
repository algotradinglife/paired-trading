# 13 — 边界情形与陷阱清单

> 实现时容易踩的坑。按主题分类，每条给出**情形 + 影响 + 处理方法**。

---

## 1. 数据输入相关

### 1.1 K 线缺失（gap）

**情形**：某根 K 线缺失（数据源问题）。

**影响**：EMA 递推中断，后续 MACD 计算异常。

**处理**：
- **不补齐**——保留 gap 让 EMA 自然处理
- 元数据中标记 gap 位置
- 不强行连续根数计数（持续度计算遇 gap 重置）

### 1.2 K 线时间戳错乱

**情形**：收到的 K 线时间戳非单调递增。

**影响**：状态机错乱。

**处理**：fail-fast，拒绝输入。这是数据源 bug，不应在系统内修复。

### 1.3 大跳空

**情形**：开盘大跳空（K 线 open 远离前一根 close）。

**影响**：
- EMA 反应延迟
- DIF 突然大幅变化
- 形态识别可能误触发

**处理**：
- 不做特殊处理（EMA 自然平滑）
- 但在输出层提示"刚出现大跳空"作为元数据
- 下游消费者可以据此调整自己策略

### 1.4 停盘与复盘

**情形**：交易暂停（午间、节假日、品种特定停盘）后复盘。

**影响**：close 跳跃，可能误触发形态。

**处理**：
- 停盘期间不计入持续根数
- 复盘的第一根 K 线**不重置**状态机
- 同样作为元数据提示下游

### 1.5 历史回放 vs 实盘的对齐

**情形**：用历史数据回放时，结果应与"当时实时计算"一致。

**影响**：实现 bug 容易导致两者结果偏差。

**处理**：
- 所有状态机必须**严格只依赖当前可见的历史**
- 严禁前瞻偏差（look-ahead bias）
- 测试时验证回放 vs 实盘一致性

## 2. 指标计算相关

### 2.1 EMA 初值偏差

**情形**：系统冷启动，EMA 用第一根 close 作为初值，前 80 根偏差较大。

**影响**：早期形态识别不可靠。

**处理**：
- 丢弃前 80 根的形态输出
- 元数据标记 `is_warmup`
- 或：用足够长的历史数据预热

### 2.2 浮点精度

**情形**：DIF 接近 0 时，浮点比较不稳定。

**影响**：穿零轴可能误判（DIF 在 0 附近反复抖动）。

**处理**：
- 用阈值 $\epsilon = 10^{-6}$ 过滤数值噪声
- DIF 在 $[-\epsilon, +\epsilon]$ 视为 0

### 2.3 各级别 MACD 数据来源

**情形**：实现者图省事，从小级别 MACD "采样"到大级别。

**影响**：MACD 是非线性函数，采样得到的值**错误**。

**处理**：
- 每个级别必须用**自己的 close 序列**重新计算 MACD
- 单元测试：对比"独立计算" vs "采样计算"，确认显著差异

## 3. 矢量单元相关

### 3.1 量能堆的"中间归零"误切

**情形**：堆内 Hist 短暂归零一根，但未真正反向。

**影响**：错把连续跳空切成两个独立堆。

**处理**：
- $g_{max}$ 参数容忍 ≤ 1 根的中间归零
- 反向柱持续 $g_{max} + 1$ 根才切

### 3.2 1 号参考点未及时失效

**情形**：周期内出现更高量能堆（跳空非背离），但 reference_heap 未更新。

**影响**：后续比较错用旧 reference，导致漏判 / 误判。

**处理**：
- 每个新 heap 形成时（heap 进入 completed 状态时）**立即**检查
- 单元测试：构造跳空非背离场景，验证 reference 重置

### 3.3 线段切换的非原子性

**情形**：实现者在两个步骤完成线段切换（关旧、开新），中间状态被其他模块观察到。

**影响**：跨级别融合层可能看到"没有 active segment"或"两个 active segments"。

**处理**：
- 设计**原子操作**：要么完成全部切换，要么不切
- 单元测试：在切换中间插入读取，验证一致性

### 3.4 同根 K 线引发多个事件

**情形**：同一根 K 线同时触发：
- DEA 穿零轴
- 多根 heap 完成
- 多个 cycle 周期间背离
- ...

**影响**：事件输出顺序混乱，依赖关系处理出错。

**处理**：
- 严格按"事件优先级"顺序处理（详见 02 第 5 节）
- 单元测试：构造多事件并发场景

## 4. 穿零轴相关

### 4.1 影线刺穿

**情形**：K 线 high/low 刺穿 EMA52，但 close 未越过。

**影响**：若用 high/low 判定 → 误触发候选。

**处理**：**严格用 close 判定**，影线不算。

### 4.2 次根回拉

**情形**：本根满足穿零轴条件，次根 close 回到原侧。

**影响**：候选失效。

**处理**：
- 标记为 `invalidated`
- 不切换线段
- 输出 `EventInvalidated` 事件

### 4.3 极短线噪声

**情形**：穿零轴确认后，几根 K 线内又回穿。

**影响**：可能是噪声引起的假突破。

**处理**：
- 已确认穿零（次根通过）仍视为有效
- 后续若反向穿越 → 触发新的穿零事件
- 不要把"确认后又回穿"也视为假突破

### 4.4 DEA 穿零但 DIF 已离开零轴较远

**情形**：罕见情形，DEA 缓慢漂移过零，但此时 DIF 已经远离零轴。

**影响**：穿零事件本身有效，但伴随的"归零轴"形态可能未成立。

**处理**：
- 穿零事件本身**只看 DEA + EMA52**
- 是否伴随"归零轴形态"是另一个独立判定
- 两者解耦

## 5. 多周期相关

### 5.1 多级别同时收盘

**情形**：4h 与 1h 在同一时刻收盘。

**影响**：状态更新次序敏感。

**处理**：
- 按**从大到小**顺序更新（大级别状态先稳定）
- 利用对齐时刻提升融合置信度

### 5.2 大级别漂移期

**情形**：周线还没收盘，但已经过去 4 天。

**影响**：大级别 live MACD 持续漂移，下游可能误用为已收盘值。

**处理**：
- 输出区分 `indicators_live` 与 `indicators_completed`
- 下游严格判定**只用 completed**
- 元数据标记 K 线"完成度"百分比

### 5.3 级别拓扑配置错误

**情形**：实现者把 A 股的 6h 级别也加入了清单。

**影响**：6h 级别永远没有数据，状态机空转。

**处理**：
- `level_registry` 按品种类型选择级别
- 启动时验证级别清单与品种类型兼容

### 5.4 嵌套链遍历的终止

**情形**：嵌套链下钻到最小级别（1m），是否继续？

**影响**：可能无限递归 / 永远等不到顶部。

**处理**：
- 嵌套链有**显式终点**（默认 1m）
- 终点级别走完 = 主级别顶部确认
- 配置最大深度防御

### 5.5 级联失效的传播停止

**情形**：小级别失效，沿链向上传播。

**影响**：所有级别都失效，系统陷入"不可信"状态。

**处理**：
- 失效传播**只触及直接长级别**，不无限蔓延
- 长级别失效是独立判定（不只是"我的子级别失效"）
- 主级别终结需要**所有**第一代第直系级别都失效

## 6. 背离判定相关

### 6.1 跨线段比较

**情形**：reference 在旧线段，candidate 在新线段。

**影响**：判定结果无意义。

**处理**：
- 比较前**强制检查** segment_id 一致
- 不一致 → 直接跳过

### 6.2 隐形的实时误判

**情形**：第一根 K 线 Hist 接近 0，价格涨了。算隐形吗？

**影响**：单根 K 线不足以判定隐形。

**处理**：
- 隐形至少需要 2 根持续（$n_2 = 2$）
- 第一根只给低置信度（~10%）

### 6.3 多次背离的累积效应

**情形**：同一线段内连续出现 3 次周期间背离。

**影响**：每次背离的置信度如何累积？

**处理**：
- 不简单累加（避免置信度爆表）
- 用宋的"乒乓球"逻辑：每次反弹高度递减
- 累积主要影响"线段终结嫌疑"，不是单个背离的置信度

### 6.4 背离的参考点变化

**情形**：周期内已经存在背离信号，但新出现更高的 heap 重置了 reference。

**影响**：背离信号失效，但下游可能已经消费。

**处理**：
- 输出 `EventInvalidated`，让下游知道
- 新 reference 后重新比较

## 7. 输出与序列化相关

### 7.1 schema 版本不匹配

**情形**：下游消费者用旧版 schema 读取新版输出。

**影响**：可能读到未知字段或缺失字段。

**处理**：
- schema_version 必填
- MAJOR 不匹配下游应拒绝消费
- MINOR 高于已知应**忽略未知字段**继续消费

### 7.2 事件优先级排序

**情形**：多个事件同 confidence，排序不稳定。

**影响**：下游可能因排序变化误判。

**处理**：
- 同 confidence 用 detected_at 作为 tiebreaker
- 排序必须**确定性**

### 7.3 输出延迟

**情形**：系统计算耗时较长，输出落后于实时数据。

**影响**：下游消费滞后数据。

**处理**：
- 输出对象包含 `system_ts - data_ts` 延迟字段
- 下游可据此决定是否消费
- 性能监控：建议延迟 < 100ms

### 7.4 内存累积

**情形**：events_history 不清理，长期运行后内存爆炸。

**影响**：系统崩溃。

**处理**：
- 历史保留有上限（默认 200 条）
- 超过的事件归档或丢弃
- 同样适用于 completed_bars

## 8. 数学不变量违反

下面是测试时应当验证的不变量。任何违反都是 bug：

| 不变量 | 测试 |
|--------|------|
| $\text{Hist}_t = 2(\text{DIF}_t - \text{DEA}_t)$ | 每根 K 线 |
| 各 confidence ∈ [0, 1] | 全程 |
| 每级别同时只有一个 live heap/cycle/segment | 任意时刻 |
| heap.parent_cycle_id 指向 active cycle | 任意时刻 |
| 同 segment 内 cycles 按 start_ts 单调递增 | 全程 |
| segment_peak_dif ≥ max(cycle.peak_dif) | 任意时刻 |
| 已确认事件不会"取消确认" | 全程 |
| 失效事件不再触发 | 全程 |

## 9. 测试用例建议

下游实现者建议构造以下测试场景：

### 9.1 基础场景
- 单边上涨完整线段
- 单边下跌完整线段
- 上涨 → 顶背离 → 穿零 → 下跌完整流程
- 横盘震荡

### 9.2 复合场景
- 多次周期间背离不破零 → 时间级别升级
- 底部变盘四阶段完整流程
- V 字反转
- 级联失效

### 9.3 边界场景
- K 线 gap
- 大跳空
- 停盘复盘
- DIF 在零附近反复抖动
- 影线刺穿 EMA52
- 隐形形态构造
- 跨线段的背离尝试

### 9.4 多周期场景
- 多级别同时收盘的对齐时刻
- 大级别漂移期监控
- 小级别先行 + 大级别滞后
- 大级别约束小级别

## 10. 已知未解决问题

下面是宋理论中**论述不严谨**或**算法翻译需要主观决定**的部分。下游实现者应记录自己的选择：

1. **"无限接近"的精确阈值** — 宋未给出，需要回测
2. **EMA52 的"附近"** — 价格距 EMA52 多近算"附近"
3. **"超强势调整"的精确边界** — K 线在 EMA24 之上多久 + DIF 衰减多少
4. **1 号参考点失效的优先级** — 多个 heap 同时形成时怎么处理（罕见但可能）
5. **嵌套链终点的选择** — 1m 还是 5m 还是 tick？
6. **K 结构分类的滞后窗口** — 多少根才算"稳定进入"该结构
7. **底部变盘四阶段的回退条件** — 反向证据持续多少根才算阶段倒退

这些都是**回测调优的对象**。实现者应当显式记录选择并在文档中说明。
