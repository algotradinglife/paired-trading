# 01 — 项目范围与边界

## 1. 项目目标

实现一个**多周期 MACD 动能分析系统**，基于宋建毅《K 线动能理论》，输出可供下游交易系统消费的结构化分析结论。

## 2. 范围内（in-scope）

### 2.1 数据输入
- 多时间级别 K 线 OHLC 数据流
- 各时间级别独立维护（不从单一级别上下采样产生其他级别 MACD）

### 2.2 指标计算
- MACD 三件套：DIF / DEA / Histogram（标准参数 12/26/9）
- 主图均线：EMA12、EMA24、EMA52（用于位置坐标）
- 各时间级别独立计算

### 2.3 单级别形态识别
- 零轴位置类：高位、高位空、零轴黏合、零轴倒挂
- 隐形形态（柱高 ≈ 0）
- 归零轴接近度（双通道：DIF 距零 + 价格距 EMA52）
- K 线走势结构：强势调整 / 超强势调整 / 弱势调整

### 2.4 时间矢量单元
- 量能堆（heap）
- 单位调整周期（cycle）
- 线段（segment）
- 1 号参考点的动态管理

### 2.5 事件判定（多档置信度）
- 归零轴：预警 → 候选 → 确认
- 穿零轴：预警 → 候选 → 确认（三重约束 + 次根确认）
- 时间级别升级：触发条件检测
- 底部变盘四阶段：状态机判定
- V 字反转：复合条件检测
- 级联失效：第一代级别失败预警

### 2.6 背离判定
- 周期内背离（量能堆 vs 量能堆）：连续跳空、分立跳空、隐形跳空
- 周期间背离（单位调整周期 vs 周期）：标准背离、动能不足、隐形
- 线段间背离（线段 vs 线段）
- 跨线段比较的硬约束

### 2.7 多周期信息融合
- 直系第一代集合扫描（启动判定用）
- 嵌套链遍历（终结判定用）
- 双向置信度传播（top-down + bottom-up）
- 跨级别协同度计算
- 第一代级别"当值有效性"维护
- 级联失效检测

### 2.8 输出
- 各级别状态快照
- 跨级别合成主标签 + 辅助标签
- 关注事件清单（按置信度排序）
- 结构化 API（schema 见 [`11-output-schema.md`](./11-output-schema.md)）

## 3. 范围外（out-of-scope）

### 3.1 下游决策层
- 具体交易动作（买卖、加减仓）
- 仓位管理 / 资金管理
- 止损 / 止盈策略
- 期权合约选择
- 不同标的的策略适配

### 3.2 外部特征工程
**多维度置信因素不在本项目处理**，包括但不限于：
- 品种特性（流动性、典型波动率）
- 时段（开盘/收盘/午间）
- 当前波动率水平
- 历史频率（该形态在该品种历史的成功率）
- 突发事件背景（公告、数据发布）
- 其他指标的协同（成交量、持仓量等）

→ 下游项目可以基于本系统输出**再叠加**这些维度。

### 3.3 系统对接
- 券商接口
- 行情源接入（本系统假设输入为已清洗的 K 线流）
- 数据存储 / 持久化（除算法所需的最小缓存外）
- 用户界面 / 可视化

### 3.4 实现层
- 本目录是**开发文档**，不包含可执行代码
- 实际实现由独立项目完成，可参考本文档

## 4. 理论边界

本系统**只采用**宋建毅《K 线动能理论》体系内的概念：

- 不引入缠论的中枢、走势级别等概念
- 不引入江恩理论、波浪理论
- 不引入肖淳心课程的趋势线、势能五度等概念
  - （这些是 wiki 内的并行知识体系，但本系统的输出语言只用宋的术语）
- 不引入机器学习模型作为主要判定路径（实现者可选用 ML 调整置信度合成参数，但不作为本规范的硬要求）

## 5. 与下游项目的接口

下游项目从本系统获得的是：

- **状态快照** —— 当前各级别的形态、单元、置信度
- **合成结论** —— 主标签 + 辅助标签
- **事件清单** —— 按置信度排序的关注事项
- **稳定 schema** —— 版本化的输出结构

下游项目自行决定：
- 在哪个置信度档位采取动作
- 用什么合约 / 仓位执行动作
- 如何叠加自己的特征工程

## 6. 性能与实时性要求（建议）

本规范不强制性能指标，但建议实现者考虑：

- 单根 K 线收盘后的形态判定 ≤ 100ms（适应 1m 级别实盘）
- 多级别并行计算（每级别一个 worker 或类似设计）
- 状态缓存可在内存中维护（除非有特殊需求，不强制持久化）

## 7. 验证维度（建议测试方向）

下游实现者应验证：

- 单根 K 线计算的正确性（数学不变量见各文档）
- 状态机转移的完整性（覆盖所有 [`13-edge-cases.md`](./13-edge-cases.md) 列出的情形）
- 多级别一致性（对齐时刻的状态对齐）
- 历史数据回放的可重现性
- 输出 schema 的向后兼容性
