OTM扫描核心发现：EV%反转，但绝对收益单调递减

权利金EV%（相对）随OTM深度增加（+32.5% → +39.9%），这是杠杆效应：便宜的权利金分母缩小， 而tp1_tp2时的大涨幅（+55% → +76%）对EV有更高权重。

绝对EV（EV×权利金，即实际利润相对F）单调递减（+0.76‰ → +0.36‰）。 如果你的目标是最大化每笔信号的绝对预期利润，ATM是最优选择。

tp1_tp2率在所有档位保持不变（66%）。这说明行权价的选择不改变"标的是否到达TP"的概率， 只影响在TP时期权本身的盈利幅度。获利率从71%降至62%，因为部分"小赢"（tp1_max/tp1_stop在ATM能盈利） 在OTM时因权利金更快衰减而变成小亏。

CN_AGRI — OTM虚值有独特优势

CN_AGRI是唯一一个 OTM深度增加时获利率不下降（保持70%）的池子。 这是因为该池的赢家（tp1_tp2）都是高波动品种（I/SC/SA，HV≈35-44%）， 标的的TP1/TP2移动（1-2×ATR）足够大，即使行权价偏移2-4%，期权仍能大幅盈利。 输家的损失（full_stop）则按ATM比例放大不多。

实际含义：CN_AGRI bottom×opp信号，可以考虑买虚2甚至虚3， 用同等权利金成本买入更多合约，EV%从+32.8% → +49.6%，而胜率不变（70%）。 这是该池特有的OTM"free lunch"效应（受限于n=23，需持续监控）。

CN_METAL — ATM显著优于OTM

CN_METAL的获利率从ATM的 78% 跌至虚4的56%。这是因为该池包含一批"TP1后小赢"交易 （RB/AU的tp1_max/tp1_stop路径），在ATM时期权有正回报，但移到OTM后这些 "小幅标的移动"已不足以让虚值期权盈利。

结论：CN_METAL坚持ATM，获利率和EV均最优（+42.1% EV, 78% win rate）。

US_EQUITY的4-tick止损：概念不直接迁移

对SPY（$480）而言，4 ticks = $0.04 = 0.008%F。期权Delta≈0.5， 所以4-tick止损导致的期权价值变化仅约 $0.02。相比ATM权利金约 $10.66（2.22%F）， 这是 0.2% 的损耗——几乎为零。

实际上US_EQUITY的"4-tick止损"在模型中等价于"几乎立即平仓"， 所以 -7.4% 损耗主要来自2天的theta衰减，而非标的移动。 肖老师的4-tick概念在US_EQUITY场景下应理解为： "若入场后2天内标的没有开始上行，则主动平仓止损"，而不是字面意义的$0.04止损。

CFFEX期权的特殊约束

  • IO上市时间：2019-12，IH对应HO上市2022-10，IC对应MO上市2022-12。 回测数据覆盖2021-2026，有效数据窗口仅3-4年，且早期流动性差。
  • 行权价粒度：IO行权价间距50点（IF在4000时≈1.25%）， 本报告用1%档位（虚2=+2%约等于1.6个行权价档），实际需取最近标准行权价。
  • n=13过小：CN_INDEX结论置信度最低，需等至n≥30后再决策。 优先用IH对应的50ETF期权（流动性更好）。
  • IC(MO)流动性差：MO成立不到3年，当月合约持仓量和流动性远不如IO/HO， 慎用。建议等n≥10独立验证。

七、跨市场执行建议

优先执行（高置信度）

  • CN_METAL bottom×opp，ATM认购：RB/AU最稳定，n=18，EV=+42.1%，获利率78%。坚持ATM，不下沉虚值。
  • US_EQUITY bottom×opp，ATM或虚2认购：SPY/QQQ/IWM，n=27，EV=+31.3%。OTM到虚2时胜率仅降4%（74%→70%），可接受。
  • US_MACRO bottom×opp，ATM认购：GLD/TLT，无全止损记录，稳定性最高。n=13，需等更多样本确认虚值是否有优势。

谨慎执行（数据支持有限）

  • CN_AGRI bottom×opp，ATM或虚2：n=23，OTM有轻微优势，但需持续观察是否为噪声。
  • CN_INDEX bottom×opp：n=13，IH(50ETF期权)流动性最好。IC的MO期权流动性差，建议跳过。
  • US_EQUITY虚3/虚4：EV%提升但绝对EV降低，获利率跌至65-62%。仅在资本受限时考虑（买多份合约）。

OTM选择总结：哪个市场用哪个档位？

CN_METAL → ATM：获利率在ATM最高（78%），OTM后急速跌至56%。不值得。
CN_AGRI → ATM或虚2：OTM获利率不变（70%），虚2 EV从+32.8%升至+42.7%，可尝试。
CN_INDEX → ATM（暂时）：样本太小，等n≥30后评估。优先50ETF期权（IH对应）。
US_EQUITY → ATM或虚2：绝对EV下降但胜率还可接受（74%→70%），虚2提供更高杠杆。
US_MACRO → ATM：无全止损，4-tick优化无意义。ATM最稳，EV+25.8%，获利率77%。
