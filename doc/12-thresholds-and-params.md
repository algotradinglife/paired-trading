# 12 — 超参清单与默认值

> 系统所有可调阈值与默认值的完整清单。每个参数附**含义、默认值、敏感度、调优建议**。

---

## 1. MACD 与 EMA 参数（不可调，标准默认）

| 参数 | 默认值 | 备注 |
|------|------|------|
| MACD 快线周期 | 12 | 严格遵循宋理论默认值 |
| MACD 慢线周期 | 26 | 同上 |
| MACD Signal 周期 | 9 | 同上 |
| EMA12 / EMA24 / EMA52 | 12 / 24 / 52 | 同上，主图均线 |
| Histogram 缩放因子 (`hist_scale`) | **1.0** | Aspray 原始为 2，但 TradingView / MT4/5 / 多数现代平台默认 1.0；本系统默认 1.0 与可视化端绝对值可比（已实测 SPY 1h/D/W 与 TV 差异 < 0.005） |

**注**：本系统**严禁修改** MACD 算法主参数（12/26/9）。`hist_scale` 可作为兼容性参数，但默认值不应改。
所有形态识别和置信度合成阶段的阈值才是调优对象。

## 2. 特征流参数（详见 04）

| 参数 | 默认值 | 含义 | 敏感度 |
|------|------|------|--------|
| `rolling_window_for_features` | 200 | 流 1/流 2 的滚动窗口（K 线根数） | 中 |
| `dif_normalization_method` | "segment_max + rolling" | 流 1 归一化方法 | 中 |
| `hist_normalization_method` | "segment_max" | 流 2 归一化方法 | 中 |
| `price_momentum_lookback` | 5 | 流 5 的 lookback 根数 | 低 |
| `state_persistence_max` | 50 | 持续根数上限（防累积过大）| 低 |

**warmup 期**：系统启动后前 80 根 K 线的形态置信度建议**降权或不输出**。

## 3. 形态识别参数（详见 05）

### 3.1 高位空（high_position_void）

| 参数 | 默认值 | 含义 |
|------|------|------|
| $\theta_1$ | 0.4 | DIF 离零轴的最大距离阈值（流 1 ≤ 0.4 才算高位） |
| Hist 衰减阈值 | 0.4 | 当前 Hist / peak Hist ≤ 0.4 才算"衰减明显" |
| 持续根数 $n_1$ | 3 | 至少持续 3 根才算高位空 |
| 权重 $w_1, w_2, w_3, w_4$ | 0.35, 0.35, 0.2, 0.1 | 合成权重 |

### 3.2 隐形（hidden）

| 参数 | 默认值 | 含义 |
|------|------|------|
| Hist 接近零阈值 $\theta_2$ | 0.05 | 流 2 ≤ 0.05 算"接近零" |
| 持续根数 $n_2$ | 2 | 至少 2 根 |
| 价格动量阈值 $\theta_3$ | 0.003 | 5 根 K 线累计涨跌幅 ≥ 0.3% |
| 权重 $w_1, w_2, w_3$ | 0.4, 0.3, 0.3 | 合成权重 |

### 3.3 零轴黏合（zero_stick）

| 参数 | 默认值 | 含义 |
|------|------|------|
| DIF 接近零阈值 | 0.85 | 流 1 ≥ 0.85 才算近零 |
| Hist 小阈值 | 0.2 | 流 2 ≤ 0.2 |
| 持续根数 $n_4$ | 3 | |
| 权重 $w_1, w_2, w_3, w_4$ | 0.35, 0.25, 0.2, 0.2 | |

### 3.4 零轴倒挂（zero_inverted）

| 参数 | 默认值 | 含义 |
|------|------|------|
| DIF 接近零阈值 | 0.85 | |
| 持续根数 $n_5$ | 2 | |
| 权重 $w_1, w_2, w_3$ | 0.4, 0.3, 0.3 | |

### 3.5 归零轴接近（near_zero_axis）

| 参数 | 默认值 | 含义 |
|------|------|------|
| 价格距 EMA52 阈值 $\theta_6$ | 0.02 | 价格距 EMA52 < 2% 算"附近" |
| 完美形态判定 | 流 1 ≥ 0.9 + 价格端 ≥ 0.95 | |

## 4. 矢量单元参数（详见 06）

### 4.1 量能堆

| 参数 | 默认值 | 含义 |
|------|------|------|
| 中间归零最大根数 $g_{max}$ | 1 | 堆内 Hist 连续归零 ≤ 1 根不切堆 |
| Hist 接近零的阈值 | $0.05 \times \text{rolling\_max}|\text{Hist}|$ | |

### 4.2 单位调整周期

| 参数 | 默认值 | 含义 |
|------|------|------|
| 出发阈值 $\tau_{\text{exit}}$ | 流 1 < 0.7 | DIF 离零轴足够远才算"已出发" |
| 归零阈值 $\tau_{\text{return}}$ | 流 1 > 0.9 | DIF 足够近才算"接近归零" |
| 归零确认根数 $n_{\text{return}}$ | 2 | 连续 2 根才确认归零 |

### 4.3 线段

无独立参数，依赖穿零轴判定（见 4.4）。

### 4.4 穿零轴

| 参数 | 默认值 | 含义 |
|------|------|------|
| 数值噪声阈值 $\epsilon$ | $10^{-6}$ | DEA 数值精度过滤 |
| 次根确认窗口 | 1 根 | 严格按宋的次根规则 |
| EMA52 击穿用 close（不是 high/low） | true | 强制规则 |

## 5. K 线结构分类参数（详见 06 第 5 节）

| 参数 | 默认值 | 含义 |
|------|------|------|

## 10. 调优指南

### 10.1 调优优先级

1. **优先调**：形态识别参数（高位空、隐形等）—— 直接影响信号触发率
2. **次优先**：多周期权重（$w_{\text{sub}}, w_{\text{up}}^\pm$）—— 影响合成置信度
3. **最后调**：归零阈值、矢量单元参数 —— 影响系统稳定性

### 10.2 调优方法建议

回测时观察：

- 各事件触发频率（过频说明阈值松，过稀说明阈值紧）
- 事件触发后的"事后正确率"（背离触发后是否真的反转）
- 不同档位的精确率 / 召回率
- 极端市场（大跳空、停盘后）的健壮性

### 10.3 跨品种 / 跨级别的差异

- **小级别（1m, 5m）**：噪声大，阈值应**收紧**（更严格才触发）
- **大级别（W, M）**：信号稀少但价值高，阈值可**放宽**（更早预警）
- **高波动品种（数字货币）**：阈值应**自适应**波动率（提示：本系统不做这个，下游自己处理）
- **低波动品种（指数 ETF）**：阈值可固定，较保守

### 10.4 不要做的事

- ❌ 不要把超参塞进代码里硬编码 —— 必须配置化
- ❌ 不要把"多维度置信因素"（波动率、时段、品种特性）塞进本系统 —— 这是下游的事
- ❌ 不要为单个事件触发独立调优 —— 应整体回测
- ❌ 不要在生产环境中频繁改参数 —— 影响下游消费者的稳定性预期

## 11. 配置文件示例（YAML）

实现者可参考下列结构组织配置文件：

```yaml
# config.yaml

macd:
  fast: 12
  slow: 26
  signal: 9

ema:
  short: 12
  mid: 24
  long: 52

features:
  rolling_window: 200
  price_momentum_lookback: 5

form_detection:
  high_position_void:
    dif_proximity_max: 0.4
    hist_decay_min: 0.4
    persistence_min: 3
    weights: [0.35, 0.35, 0.2, 0.1]
  hidden:
    hist_amplitude_max: 0.05
    persistence_min: 2
    price_momentum_min: 0.003
    weights: [0.4, 0.3, 0.3]
  ...

vector_units:
  heap:
    max_gap_zero: 1
  cycle:
    departure_threshold: 0.7
    return_threshold: 0.9
    return_confirm_bars: 2

zero_axis_crossing:
  numerical_epsilon: 1e-6
  next_bar_confirmation: true

multi_timeframe:
  w_sub: 0.4
  w_up_plus: 0.3
  w_up_minus: 0.4
  k_structure_modifiers:
    inter_cycle_divergence_x_strong: 1.1
    inter_cycle_divergence_x_ultra_strong: 0.9
    inter_cycle_weakness_x_weak: 1.15

confidence_stages:
  dormant: 0.30
  watching: 0.50
  forming: 0.65
  candidate: 0.80
  confirmed: 0.95

symbols:
  "BTC-USDT":
    levels: [1m, 5m, 15m, 30m, 1h, 2h, 4h, 6h, 12h, D, 3D, W, M]
  "000001.SZ":
    levels: [5m, 15m, 30m, 1h, 2h, D, 2D, 3D, W, 2W, M, Q]
```

实现者按语言/框架选择具体配置形式。
