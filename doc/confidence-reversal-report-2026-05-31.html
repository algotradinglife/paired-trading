设计期望 vs 现实

置信度得分应反映信号质量：low → 信号弱，high → 信号强， 预期 EV 单调递增（low < mid < high）。

但三段样本量几乎均等，说明切分是纯分位数设计——它描述"相对于同一批信号的位置"， 而不是"绝对信号质量的阈值"。这本身不会导致单调性失效，但意味着极端效果只能在有强信号时才出现。

核心发现：confidence_band 不代表"信号质量"

10个 pool×direction 组合，无一满足预期的单调性（low < mid < high）。 这不是统计噪声——它是系统性的：指标设计没有捕捉到方向性胜率。

最可能的原因：置信度得分衡量的是背离的几何深度/形状完整性（如能量柱萎缩幅度、 背离跨度），而不是"标的价格是否会上涨"。几何完整性和价格方向性是两个不同的概念， 在顶部信号时尤其容易错位（下跌中继 vs 真正底部的几何形态可能相似）。

过滤效果：真实但统计力度不足

剔除 top×conf=mid 后 Sharpe 从 0.263 → 0.317（提升 +0.054），EV 从 +0.300R → +0.367R。 看起来有价值——但有两个问题：

  • top×mid 的 CI95 = [−0.044, +0.359]，跨越零轴。mid 不是"可证明的负EV"，只是"显著偏弱"。
  • 过滤掉 n=115 笔交易（占 top 信号 32%），是很大的样本损失——若机制不清楚， 未来可能出现截然相反的行为。

六、关键结论：h=opposing 滤波器完全覆盖置信度信号

bottom × h=opposing 后，三个置信段 EV 完全重叠，置信度提供零增量信息

   conf=high 31 +0.699R [+0.321, +1.077] ✓ 65%61%23%

h=opposing 是比 confidence_band 强得多的质量过滤器

一旦应用 h=opposing 过滤，bottom 信号在三个置信段的 EV 分别为 +0.900R / +0.952R / +0.699R，置信区间高度重叠，置信度对 EV 没有任何增量预测力。

这意味着：confidence_band 捕捉到的信息已经被 h=opposing 所包含。 h 方向的时间结构（1小时趋势是否与日线背离方向对立）是一个更直接的价格行为信号， 能覆盖几何形态分类无法捕捉的信息。

七、时间稳定性：信号是否在早晚两期一致？

晚期 2023-11→2026 384 +0.569R +0.314R +0.435R 是（mid 偏弱，Δ=−0.185R）

时间稳定性不足：mid 弱势在早期不存在

2021-2023 期间，mid 表现最好（+0.400R）。2023-2026 期间 mid 变弱（+0.314R）， 成为最弱段。这种模式翻转是红旗：如果 mid 弱势是真实的结构性规律，应在两期都存在。

更可能的解释：2023-2026 的市场机制（CN 宏观波动放大、US 科技牛市结束） 恰好与置信度分布的某段相关，但这是 regime 巧合而非因果关系。

八、结论与行动建议

不做的事

  • 不添加 conf=mid 过滤规则：统计力度不足（CI 跨零），机制不明，在底部信号中 mid 甚至偏强
  • 不在 h=opposing 场景下使用置信度：h=opp 已覆盖所有置信段信息，额外过滤是过拟合
  • 不用置信度做仓位调整：无单调性，高置信度不等于更大仓位
  • 不拆分 bottom vs top 各自建置信度规则：方向依赖强烈，跨方向的规则会互相伤害

正确的处理方式

  • confidence_band 定位为诊断指标，不是过滤器：记录在信号日志中，但不触发入场/跳过
  • 主过滤器保持 h=opposing：这是经过 walk-forward OOS 验证的唯一稳健过滤器
  • 重新审视置信度得分的计算逻辑：当前指标可能衡量背离几何完整性而非方向性概率； 需要引入价格动量或时间维度才能改善预测力
  • 监控 top×conf=mid：随 n 增长持续跟踪；若到 n=200 后 CI 仍不跨零，才考虑软降权

系统性教训：为什么置信度指标会"反转"？

confidence_band 衡量的是背离形态的几何完整性（能量柱缩量幅度、相邻波段高度差等）。 这在"标的是否回调"的预测中有价值，但在"回调是否是真正反转"的判断上存在盲点：

  • 高置信度背离（high）：几何清晰，但在强趋势市场中也会出现高清晰度的假背离—— 趋势惯性强，反转概率不一定高
  • 低置信度背离（low）：形态残缺，但往往发生在极端恐慌或超卖区间， 均值回归动力更强
  • 中等置信度背离（mid）：既不够清晰（引不来追随资金），又不够极端（缺乏均值回归驱动）—— 这解释了为什么 mid 在顶部信号里是最弱的：顶部 mid 信号是"既不是清晰反转，也不是极度恐慌"的模糊地带

底部信号的 mid 没有同样问题，因为底部 mid 的"模糊"恰好与市场犹豫期重叠——此时价格往往 停止下跌（支撑），所以 mid 在底部反而不弱。
