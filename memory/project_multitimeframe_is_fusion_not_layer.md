`macd-momentum` 项目的一个架构性原则：**多周期分析不是"在所有单级别形态判定之上"的一个独立模块，而是渗透到每个形态判定本身的信息融合层。**

**Why（用户洞察）：**
> 我感觉有些模糊的概念是否放到多周期场景下会做更好的判断。

宋建毅的"嵌套关系"本质上是个**贝叶斯信息融合框架**——不同时间级别是相互独立的观测通道，各自带噪声，但融合后的后验比任何单通道都强得多。

**对系统架构的核心影响：**

层次应该是：

```
Layer 1: 单时间级别的特征流提取
        （DIF 距零、Hist 高度、Hist-DIF 符号、持续根数、价格增量）
              ↓
Layer 2: 单时间级别的形态预置信度
        （高位空、隐形、黏合、倒挂... 在单级别上的初步置信度）
              ↓
Layer 3: 多时间级别的信息融合
        （把多个级别的预置信度合成为最终置信度）
              ↓
Layer 4: 期权决策动作
```

**不能跳过 Layer 3 直接从 Layer 2 跳到 Layer 4**——因为单级别的形态判定有天然的模糊区，必须通过其他级别"投票"才能解模糊。

**典型例子：**

| 形态 | 单级别模糊 | 多周期解模糊 |
|------|----------|------------|
| 隐形 | "价格涨 + Hist≈0"是隐形还是噪声？ | 看长级别 Hist 是否在释放——是 → 1h 那个不算隐形；否 → 隐形成立 |
| 黏合 vs 倒挂 | 过渡期形态相似 | 看次级别动量方向——同向 → 黏合；反向 → 倒挂 |
| 高位空 | Hist 衰减是终结还是局部？ | 看长级别状态——长级别也弱 → 终结概率高 |
| 归零轴 | DIF 接近零是即将反弹还是即将穿越？ | 看次级别——次级别已完成线段调整 → 反弹；未完 → 穿越 |

**对宋理论的重新理解：**

宋讲"嵌套关系"时把它放到第六章，看起来是个高阶概念。但实际上嵌套关系**本身就是单级别形态的信息源**——不引入嵌套，单级别的任何形态判定都是高噪声的。

宋的"诸葛亮+五虎上将"类比里，**每个级别的状态都被其他级别约束**——这就是信息融合，只是宋用历史故事讲。

**How to apply:**

1. 概念讲解时，**Layer 6（多周期）的内容要提前渗透到 Layer 3-5**，不能等到最后才讲
2. 设计算法时，**形态置信度必须是多时间级别的合成函数**，不能在单级别上输出最终判定
3. 后续 wiki 修订时，每个形态页都要有"多周期增强判定"小节
4. 代码架构上，**单级别形态检测器** vs **多级别融合器** 要是两个独立模块，不要把融合逻辑写进单级别检测器里
