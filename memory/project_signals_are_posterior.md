`macd-momentum` 项目的一个基础认识论原则：**MACD 动能理论里所有的"事件"——归零轴、背离、穿零轴、变盘、底部、顶部——本质都是后验概念，实时不可知**。

**Why（用户洞察）：**
> 归零轴就像价格的"底"一样，只能事后确认，事前更多是怀疑和推测。不过在肖老师飞天期权体系下，**有怀疑就可以开始埋伏了**。

**展开：**
- 归零轴的定义是"DIF 趋近零 + K 线触 EMA52"——但"趋近"是过程不是事件
- 实时只能观察到：DIF 与零轴的距离、价格与 EMA52 的距离
- 是否"已经归零并即将反弹" vs "正在向下穿越" 在事前**完全不可区分**
- 同样的逻辑适用于所有 MACD 形态：背离要等下一波证伪、穿零轴要等次根 K 线、变盘要等长级别给方向

**对系统设计的核心影响：**

1. **不要输出离散事件，输出连续置信度**
   - 不说"归零轴触发"，说"归零轴置信度 78%"
   - 不说"顶背离形成"，说"顶背离置信度 65%"
   - **"置信度"是用户确认的统一术语**（2026-05-20）——后续讨论和代码接口都用这个词，不混用"嫌疑度""可能性""概率"等同义词

2. **信号分级，对应不同操作动作**
   | 置信度 | 阶段 | 期权动作 |
   |--------|------|---------|
   | 低（怀疑） | 距离阈值进入预警区 | 准备、不动 |
   | 中（埋伏） | 多个指标同向叠加 | **轻仓试探 + 严止损** |
   | 高（形态成立） | 价格 + DIF + 时间多重确认 | 加仓 |
   | 后验确认 | 反向走势已发生 | 已经在持仓中 |

3. **"怀疑就埋伏"是期权的核心优势**
   - 飞天期权框架直接利用了"事后确认无法操作"的反面
   - 期权的非对称收益结构（严止损 + 时间价值低）让"怀疑阶段进场"在数学上是正期望
   - 等到后验确认 = 错过最佳进场点 + 权利金已贵

4. **算法目标是给出"怀疑级"信号的质量评估**
   - 而不是"事件检测"
   - 决策权交还给交易者：用什么置信度入场是策略问题，不是算法问题

**How to apply:**
- Layer 3 之后讲每个形态时，**都要点明"这是后验概念，实时只能推测"**
- 设计输出接口时，每个信号必带置信度 + 距离阈值 + 同向指标数
- 不要给"已确认"的二值标志（除非已经过了次根 K 线等强约束）
- 与"期权左侧交易"记忆联动：怀疑阶段 = 左侧窗口

**与宋理论的对应：**
- 宋的"幸运买点"本质就是怀疑阶段进场
- 宋的"理性买点"本质是等待后验确认（嵌套链走完）
- 宋承认两者都可操作，只是评估的风险不同（标的资产视角）
- 期权改变了两者的相对价值——怀疑阶段（左侧）反而成为主战场
