`macd-momentum` 项目的**严格范围边界**（用户 2026-05-20 明示）：

> 本项目我们立足于分析和概率估算。具体与期权或者股票如何对接是另外的项目来涉及。具体场景还有不同维度是置信考虑因素。

**项目内（in-scope）：**
- K 线 OHLC 数据输入
- 多时间级别 MACD / EMA52 / EMA24 / 量能堆 / 单位调整周期 / 线段等矢量单元的状态维护
- 单级别形态的预置信度估算（高位空、隐形、零轴黏合/倒挂等）
- 跨级别信息融合后的最终置信度（**只用 MACD 动能理论体系内的信息**，不引入外部特征）
- 各类背离（周期内 / 周期间 / 线段间）的判定与置信度
- 穿零轴事件的多档置信度（预警 / 候选 / 确认）
- 时间级别升级、底部变盘四阶段等复合状态判定
- K 线走势结构（强势/超强势/弱势）作为宋理论内的修饰因子

**项目外（out-of-scope）：**
- 期权合约选择
- 股票仓位管理
- 止损/止盈策略
- 资金管理
- 任何具体交易动作
- 与券商/交易所的对接
- **多维度置信因素合成**（2026-05-20 明示）：品种特性、时段、波动率水平、历史频率、突发事件背景、其他指标协同等**外部特征工程**都属于下游项目
- 任何代码实现（2026-05-20 明示）

**架构边界：**

```
─────────── 本项目 ───────────
K 线数据
  → 多周期 MACD 状态
  → 形态预置信度
  → 多周期 + 多维度融合
  → 最终置信度 + 事件标签
─────────── 输出 ─────────────
  ↓
─────── 下游项目（独立项目）───────
期权策略 / 股票策略 / 风控 / 执行 ...
```

**置信度合成的输入维度（仅限宋理论体系内，2026-05-20 修正）：**
本项目的置信度合成只接受 MACD 动能理论体系内的输入：
- 多周期协同（已讨论）
- K 线走势结构（强势/超强势/弱势）— 这是宋理论内的概念
- 时间矢量单元的层级（量能堆 / 单位调整周期 / 线段）
- 各级别状态之间的依赖与协同度

外部维度（品种、时段、波动率、历史频率、突发事件、其他指标）**不在本项目处理**——下游项目可以基于本项目的输出**再叠加**这些维度做最终决策。
